## Root Cause Analysis

### Error Details

All 12 tests failed with the same error:

```
TypeError: fetch failed

AggregateError:
  - Error: connect ECONNREFUSED ::1:3000
  - Error: connect ECONNREFUSED 127.0.0.1:3000
```

### What This Means

1. **The tests attempted to connect to `localhost:3000`** — This is where the Next.js development server should be running
2. **Connection was refused** — No server was listening on port 3000
3. **Both IPv6 (::1) and IPv4 (127.0.0.1) failed** — The server was completely unavailable

### Why This Happened

The QA tests require a running development server because they:
- Make HTTP POST requests to `/api/chat`
- Test the full stack (API routes → Claude API → response parsing)
- Cannot run in isolation without the server
