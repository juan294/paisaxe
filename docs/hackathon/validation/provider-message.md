# Provider message (Tier B)

Owner sends this by email or WhatsApp to three to five Asturias activity providers by
2026-10-09 (plan, Phase 5, unit 5b). Any reply counts as evidence. The message asks for
opinions only; it does not ask anyone to sign up, list activities or take bookings.

Record each send (provider, channel, date) and each reply verbatim, with the sender's
permission to quote, in `results.md` in this folder.

## WhatsApp version (short)

> Hola, soy Juan, de Paisaxe (https://paisaxe.es), una web para descubrir Asturias
> conversando con un guía virtual. Estoy probando que, desde esa conversación, un
> visitante pueda reservar una actividad y pagar una señal. No busco que os apuntéis a
> nada: solo me ayudaría mucho vuestra opinión en tres preguntas, aunque sea en una línea
> cada una.
>
> 1. ¿Cómo os llegan hoy las reservas (teléfono, WhatsApp, web, plataformas)?
> 2. ¿Os ahorraría trabajo recibir reservas ya cerradas, con fecha, personas y una señal
>    pagada?
> 3. ¿Qué os haría no usar algo así?
>
> ¡Muchas gracias!

## English summary (for the submission)

Three questions to providers: how bookings arrive today; whether confirmed bookings with
a paid deposit would save work; what would stop them using it. Replies are quoted only
with permission.
