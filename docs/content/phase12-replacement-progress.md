# Phase 12: replacing guide-derived content

Phase 12 is the content and image provenance part of the GitHub issue plan. Earlier phases addressed other software and operational issues. This phase replaces material derived from the downloaded guides, whose reuse permission remains unconfirmed, with independently written text supported by documented permitted sources. Images are reviewed separately.

Openly accessible material is not automatically licensed for reuse. We are using individually reviewed structured sources, including Wikidata's CC0 data and narrowly qualified official Asturias datasets. This gives the replacement a documented provenance basis; it is not a guarantee against claims.

The latest work adds twenty-one subjects to the factual basis. Eighty-four unchanged official field values support twenty-eight place identities, with seven subjects overlapping the earlier reviewed set. Fifty-six values are names/municipalities; twenty-eight are opaque identifiers retained for traceability. These are starting facts, not completed descriptions.

The local importer checks selected fields against the actual retained source file, including its hash, record ID and original index. Database checks enforce the narrow field/license/source contract and refresh deadlines. Chat citations preserve the source, license link, publisher, change notice and explicit unknown publisher date/year.

The remaining work is to qualify the uncovered subjects, write the full replacement from reviewed facts, check overlap and factual/cultural quality, and complete the forty-question comparison. Every displayed image needs an accepted replacement or the accepted disclosed fallback. Billed embeddings/answer capture require a concrete budget proposal. Publication must then verify the actual released corpus, citations, images and retirement of old serving content.

Phase 12 is still in progress. The existing production content has not been replaced by this local work, and issues #986/#987 remain open.
